# GoNoGo – Phoenix Ideas Design System

## 🎨 Color Palette

### Neon Accents
- **Primary (Magenta)**: `#FF2DF1` - Operations & Tenant Experience
- **Secondary (Cyan)**: `#2DF9FF` - Technology
- **Success (Lime)**: `#C6FF00` - Sustainability

### Text Colors
- **Primary Text**: `#EDEDED` - High contrast, readable
- **Muted Text**: `#A0A0A0` - Secondary information
- **Background**: `#000000` - Pure black

## 🔤 Typography

### Hierarchy
- **Headlines**: Bold (700), neon color with text-shadow glow
- **Body Text**: Medium (500), `#EDEDED` for readability
- **Labels**: Bold uppercase, `#A0A0A0` for subtle hierarchy

### Contrast
- High contrast between text and background
- Neon glows enhance readability without overwhelming

## 🎯 Interactive Elements

### Buttons
- **Large tap targets**: Minimum 60px height
- **Neon glow**: `box-shadow: 0 0 40px {color}80, 0 0 80px {color}40`
- **Bold text**: Clear, confident CTAs
- **Rounded corners**: 16px (rounded-2xl)

### Inputs
- **Border**: 2px solid with neon accent on focus
- **Background**: `rgba(255,255,255,0.05)` - subtle depth
- **Padding**: Generous (20px+) for comfortable interaction

## ✨ Neon Effects

### Glow Intensity
- **Subtle**: 15-20px blur, 40-50% opacity
- **Medium**: 25-35px blur, 60-70% opacity
- **Strong**: 40-80px blur, 80% opacity (dual-layer)

### Animations
- **Pulse**: 2s ease-in-out infinite
- **Logo Glow**: 3s ease-in-out infinite
- **Transitions**: 300ms for smooth interactions

## 🏷️ Veralogix Logo

### Design
- Circular badge with "VERALOGIX GROUP" text
- "JOINING THE DOTS" tagline
- Globe/network icon in center
- Neon lime (`#C6FF00`) with animated glow

### Placement
- Fixed top-left (24px from edges)
- 80x80px size
- Visually separated from content
- Soft drop-shadow glow effect

## 📱 Responsive Design

### Mobile-First
- Cards: 90vw max-width
- Touch-friendly: 60px minimum tap targets
- Generous padding: 24-32px
- Readable text: 16-18px base size

### Desktop
- Centered layouts with max-width constraints
- Enhanced glow effects (more visible on larger screens)
- Smooth animations without performance impact
