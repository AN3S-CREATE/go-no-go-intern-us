# Intern Us Feature Selection Tool - User Guide

## 🎯 Purpose

This tool helps executives and stakeholders evaluate and select features for the **Intern Us** platform - a comprehensive digital ecosystem designed to connect South African students with career opportunities.

---

## 🚀 Quick Start

### Step 1: Privacy Agreement
- Review and accept the privacy terms on the first screen
- This ensures your selections remain confidential

### Step 2: Onboarding
- Learn how the tool works through 3 simple slides
- Enter your name to personalize your experience
- Click "Start Exploring" to begin

### Step 3: Feature Selection
- **Swipe LEFT** (or click ✗) to skip a feature
- **Swipe RIGHT** (or click ❤️) to select a feature
- **Tap "Learn More"** to see detailed information

## 🌟 Best Practices

### For Effective Evaluation

1. **Read Info Cards First**
   - Start with the category overview
   - Understand the purpose before diving into features

2. **Use Learn More Liberally**
   - Don't rush through cards
   - Detailed view provides crucial context
   - AI assistant can answer specific questions

3. **Think Holistically**
   - Consider how features work together
   - Balance AI and non-AI features
   - Think about student needs and constraints

4. **Consider the South African Context**
   - Internet connectivity challenges
   - Mobile-first usage patterns
   - Multilingual requirements
   - B-BBEE and compliance needs

### Decision Framework

Ask yourself:
- ✅ **Essential:** Must-have for core functionality?
- 🎯 **Impact:** High value for students?
- 💰 **Feasible:** Realistic to implement?
- 🔗 **Integrated:** Works well with other features?
- 🌍 **Contextual:** Addresses SA market needs?
