## 🎯 **How Voting Works**

### Executive Journey:
```
1. Click link → Opens on phone
2. Privacy screen → Accept terms
3. Onboarding → Learn how to use (3 slides)
4. Enter name → Identifies their votes
5. Vote on 75 features:
   - Info card (AI Features)
   - 25 AI feature cards
   - Info card (Non-AI Features)  
   - 25 Non-AI feature cards
   - Info card (Gimmicky Features)
   - 25 Gimmicky feature cards
6. Completion → All votes logged
```

### Voting Actions:
- **Swipe RIGHT (❤️)** = YES vote (logged)
- **Swipe LEFT (✗)** = NO/skip (not logged)
- **Tap card** = View details (optional)

### Time per Executive:
- **Quick pass:** 10-15 minutes
- **Thorough review:** 20-30 minutes
- **Deep analysis:** 40-60 minutes

## 📊 **Data Capture Format**

### Console Log Output:
```javascript
Feature selected: {
  user: "Executive Name",
  feature: "AI-powered smart matching",
  category: "ai-features",
  timestamp: "2025-11-25T14:30:00.000Z"
}
```

### What Gets Logged:
- ✅ **YES votes only** (right swipes)
- ✅ **User name** (entered during onboarding)
- ✅ **Feature title** (exact name)
- ✅ **Category** (ai-features, non-ai-features, gimmicky-ai)
- ✅ **Timestamp** (ISO format)

### Data Collection:
1. Open browser console (F12)
2. Filter for "Feature selected"
3. Copy all logged votes
4. Export to spreadsheet
5. Aggregate votes per feature
6. Identify top features
